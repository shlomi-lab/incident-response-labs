# 🛡️ Incident Response Labs

> A collection of hands-on Incident Response investigations covering malware analysis, registry forensics, network traffic analysis, persistence mechanisms, and ransomware investigations.

---

## 📖 Overview

This repository documents practical Incident Response labs completed during cybersecurity training.

Each scenario focuses on identifying attack techniques, analyzing evidence, determining the attack timeline, and documenting the investigation process.

---

## Skills Demonstrated

- Incident Response
- Digital Forensics
- Malware Analysis
- Registry Analysis
- Network Traffic Analysis
- Persistence Analysis
- IOC Identification
- Timeline Reconstruction
- Wireshark
- Process Monitor
- Registry Explorer
- VirusTotal

## Labs

### 🔹 CySourceCorp Scenario

Investigation of a ransomware intrusion using network traffic analysis.

Topics covered:

- HTTP/TLS Flood detection
- Brute-force authentication attempts
- Malware download analysis
- CertUtil abuse
- SHA1 identification
- LockBit ransomware investigation

---

### 🔹 Njrat Malware Scenario

Analysis of a NjRAT infection.

Topics covered:

- Malware persistence
- File creation
- Process analysis
- Command & Control communication
- Registry modifications
- Incident mitigation

---

### 🔹 Registry Scenario

Windows Registry forensic investigation.

Topics covered:

- Registry persistence
- Backdoor execution
- Timeline analysis
- Remote address identification
- Registry ASEPs
